# Internet Radio LS / Los Santos Multimedia v1.0.1 Public Beta

This public beta is based on the tested **TEST74.2 Safe Close Request Hotfix**.

## Highlights

- Complete in-game multimedia/head-unit style interface
- 61 internet radio stations across 10 categories
- 13 visual themes
- 7 interface languages
- YouTube Music and Spotify media-session integration
- Live metadata where supported
- Optional audio-reactive visualizer, vehicle neon and cabin light
- Improved icon alignment and restrained neon accent pedestal
- Safe menu-close-on-press fix based on the stable TEST73 branch

## Public-release safeguards

- GTA V **single-player only**
- GTA Online/network-session guard included
- No third-party album/track cover files bundled
- Media Artwork defaults to **OFF** on fresh installs
- Neutral/mod-created provider icons in the public build
- Runtime artwork cache cleanup
- No developer telemetry or analytics
- Legal, third-party and privacy/network notices included

## Requirements

- GTA V for Windows
- ScriptHookV
- ScriptHookVDotNet
- Windows PowerShell
- Internet connection for radio streams and optional media-service integrations

## Installation

Extract the ZIP into your GTA V installation directory and keep the included `scripts/InternetRadio/` folder structure intact.

## Notes

Third-party radio streams can change, go offline or be geo-blocked. YouTube Music and Spotify integration depends on the corresponding third-party software/services and Windows media-session behavior.

This is an unofficial independent fan-made modification and is not affiliated with or endorsed by Rockstar Games, Take-Two Interactive, Spotify, Google, YouTube, or any radio/stream provider.
