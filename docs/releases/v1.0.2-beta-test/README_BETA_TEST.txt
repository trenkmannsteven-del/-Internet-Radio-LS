LOS SANTOS INTERNET RADIO LS v1.0.2 BETA TEST

INSTALL:
1. Close GTA V.
2. Copy the included "scripts" folder into your GTA V main directory.
3. Keep the folder structure intact.
4. Make sure your Windows user has read/write/modify access to scripts/InternetRadio/.
5. Start GTA V Singleplayer and press NUM0 in a supported vehicle.
