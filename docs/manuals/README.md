# User Manuals

The `pdf/` folder contains ready-to-read manuals for users. The `source/` folder contains the editable Markdown used to produce them.

Supported languages match the seven in-game UI languages:

- DE - Deutsch
- EN - English
- ES - Español
- FR - Français
- IT - Italiano
- PT-BR - Português (Brasil)
- TR - Türkçe

All current PDFs document **Internet Radio LS v1.0.2 BETA TEST**, based on the tested **v7.41** build.
